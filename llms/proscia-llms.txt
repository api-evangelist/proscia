# Proscia

> Proscia is a digital pathology software company whose Concentriq platform powers AI-driven precision medicine and diagnostic pathology for clinical labs, pharma/biotech R&D, CROs, and academic research. Concentriq is an open, API-first platform (REST API, Custom APIs, SDK, Model Context Protocol data backbone, Concentriq Embeddings foundation-model API, Compute, and Analysis API). Proscia is SOC 2 Type II, ISO 27001, and ISO 13485 certified, HIPAA/GDPR aligned, with FDA 510(k)-cleared and CE-IVDR-marked diagnostic products.

## APIs

- [Concentriq Platform API](https://proscia.com/build-on-concentriq/): REST API over whole-slide images, annotations, regions of interest, users, and clinical/case data. Auth via Concentriq API key (concentriq-api-key header), JWT bearer, or basic (email+password → JWT); enterprise SAML SSO.
- [Concentriq Embeddings API](https://github.com/Proscia/proscia-ai-tools): Foundation-model API extracting visual embeddings from slides using DinoV2, PLIP, ConvNext, CTransPath, H-optimus-0, and Virchow.
